# Antivirus notice

Some antivirus engines flag `LunarHitFixInstaller.exe` v0.1.1. We believe these
may be false positives, but the vendors have not confirmed that assessment.

**The EXE has not been modified or replaced.** This update only simplifies the
GitHub documentation.

The installer and Java agent are open source, so you can inspect what they do
and build them yourself. The [public source verification](https://github.com/slytess/hit-fix-minecraft-lunarclient/actions/runs/38978435902)
passed. Microsoft Defender found no threats during our local scan; that result
does not override other engines' verdicts.
